# Shop

A responsive online shop built with React and TypeScript using the DummyJSON API. Users can browse, search, filter and paginate products, view product details, log in, manage a shopping cart and view their profile. Cart and profile pages are protected for authenticated users.

> Registration is simulated for demonstration purposes. It uses mock data and does not create a real account on a server.

## Dependencies

Main technologies:

- React
- TypeScript
- Redux Toolkit and React Redux
- React Router
- Webpack
- Vitest and Testing Library
- ESLint
- DummyJSON API

## Setup and Launch

1. Clone the repository:

   ```bash
   git clone https://github.com/omeredova/shop.git
   cd shop
   ```

2. Install dependencies:

    ```bash
    npm install
    ```

3. Start the development server:

    ```bash
    npm start```

## Available Commands

```bash
npm start          # Start the development server
npm run build      # Create a production build in dist/
npm run preview    # Preview the production build
npm test           # Run tests
npm run lint       # Check code with ESLint
npm run type-check # Check TypeScript types
